Download **Nextstep-0.3.1-macOS-arm64-DMG.zip** from Assets below.

For Apple silicon Macs (M1 or later). Both the app and DMG are signed with Developer ID and notarized by Apple.

### Install

1. Unzip the download and open the DMG.
2. Drag Nextstep into Applications, then eject the disk image.
3. Open Nextstep from Applications and follow the setup wizard.
4. Choose Codex or Claude Code to help find and save jobs, or use the board manually.

### Included

- Kanban board and list view backed by local SQLite.
- Guided setup with Codex and Claude Code options.
- Compact header and the new Nextstep logo.
- Search preferences and Interested / Uninterested feedback to guide agent searches.

New installations start empty. Personal jobs, preferences, and credentials are not included. Existing Nextstep databases are preserved when updating.

Scheduled searches are created in your chosen agent after you send the setup request. Keep your computer awake and the agent running for scheduled searches.
